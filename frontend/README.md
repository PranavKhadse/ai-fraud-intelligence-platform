# Frontend — Fraud Intelligence Dashboard

This directory will contain the React + TypeScript frontend dashboard for the Fraud Intelligence Platform.

## Planned Scope (Phase 11 & Phase 12)
- **Live Transaction Feed**: Real-time visualization of incoming transactions with risk scores and status badges.
- **Analyst Case Queue**: Investigation portal for flagged `REVIEW` cases with triage and search filtering.
- **Explainability Visualizer**: Detailed case inspection views displaying TreeSHAP waterfall charts and reason codes.
- **Risk Metrics Analytics**: Aggregate volume, fraud rates, and score distribution charts.

*Development for this component will be initialized during Phase 11.*
